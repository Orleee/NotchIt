It tells you what just happened.

Small events pop out of the pill and go away on their own.

  • Power. Charging started, low battery.
  • Volume. A dot that follows the level.
  • Keys. Caps Lock and Num Lock indicators beside the notch.
  • Privacy. Which app is using your camera or microphone.
  • Time. Timer finished, Pomodoro changes, calendar reminders.

# timer, note, task
t 10
n buy milk
todo pay electricity

# tools
screenshot
color
pomodoro

Send it your own alerts.

A small token-protected HTTP API listens on 127.0.0.1 only, so scripts on your PC can push a notification to the island or read its status. The tray menu copies a ready-made example for you.

  • /ping checks that it’s running.
  • /notify (or /send) shows a notification.
  • /status returns the current state.
# token is saved in %APPDATA%\DynamicIsland\token.txt
$t = Get-Content "$env:APPDATA\DynamicIsland\token.txt"
Invoke-RestMethod "http://127.0.0.1:<port>/notify?token=$t&app=Downloader&title=Download%20done&text=video.mp4"

Stays on your PC.

The audio visualizer is analyzed in memory and never stored. The API only accepts local, token-authenticated requests. Message content can be hidden, clipboard history can be turned off, and a focus mode holds notification pop-ups, automatically during fullscreen apps and presentations. Settings and data live in %APPDATA%\DynamicIsland. The only network calls are for weather, lyrics and exchange rates.

Build it yourself.

One C# source file, WPF, no NuGet packages. It compiles with the csc.exe that ships with Windows, using the included bangun.bat. Requires Windows 10 or 11.

# from the project folder
bangun.bat
